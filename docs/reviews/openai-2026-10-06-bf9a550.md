Blocker, lib/redmine_issue_field_visibility/patches/application_controller_patch.rb:18-23
The hide_values wrapper is applied only around render_to_body. Issue PDFs are generated in the action via send_data(issue_to_pdf(...)) before rendering happens, so hide_values? is false when issue_to_pdf reads the issue. As a result, hidden fields (notably description) still appear in the PDF.
Concrete failure: As a user with description hidden (e.g., Reporter from the e2e seed), request /issues/1.pdf. The PDF contains “Secret description…”, despite being hidden on HTML, Atom, API, mail, and webhooks.
Fix: Wrap hide_values around the execution of the IssuesController show action for read-only formats, not just rendering. For example, add an around_action on IssuesController (new patch file) that enables hide_values for GET/HEAD of show/index (and specifically for format.pdf), so the PDF builder reads hidden-aware values:
- Create lib/redmine_issue_field_visibility/patches/issues_controller_patch.rb:
  module RedmineIssueFieldVisibility::Patches
    module IssuesControllerPatch
      def self.included(base)
        base.around_action :ifv_hide_values_for_readonly, only: [:show, :index]
      end
      private
      def ifv_hide_values_for_readonly
        if request.get? || request.head?
          RedmineIssueFieldVisibility.hide_values { yield }
        else
          yield
        end
      end
    end
  end
  IssuesController.include RedmineIssueFieldVisibility::Patches::IssuesControllerPatch
- Alternatively (narrower), wrap only when request.format.pdf? in the around_action.

Resolution: not a bug. IssuesController#show (and #index) only send the headers in format.pdf; the PDF is built by issues/show.pdf.erb (issues/index.pdf.erb), so it is rendered inside render_to_body and inside hide_values (Redmine 5.1 and 7). Proven by test_show_pdf_should_not_contain_hidden_description, added in b2fe8a5, which reads the PDF text and fails with the readers unguarded; and on the e2e server (MariaDB) pdftotext of /issues/1.pdf finds the description once as manager and not as reporter.
